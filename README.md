## 👋 About

A collection of small React projects I built while learning. Each project focuses on one concept, so it is easy to read, run, and revisit.

## 🧠 What I Practiced

| Area | Topics |
|---|---|
| 🪝 **Hooks** | `useState`, `useEffect`, `useRef`, `useReducer` |
| 🖱️ **Events** | `onClick`, `onChange`, `onSubmit` |
| 🧩 **Components** | Props, `children`, reusable `Card`, `Avatar`, `Button` |
| 🔀 **Rendering** | `&&`, ternary, early return |
| 🧭 **Routing** | React Router v6 with `Routes`, `Route`, `Link`, 404 page |
| 📝 **Forms** | Controlled inputs, submit handling, result card |
| 🎨 **Styling** | Flexbox, gradients, custom modal instead of `alert()` |

## 🛠️ Tech Stack

- ⚛️ React
- ⚡ Vite
- 🧭 React Router DOM v6
- 🎨 CSS

## 🚀 Run a Project

<details>
<summary><b>Click to see the steps</b></summary>

<br>

```bash
# 1. Clone the repository
git clone <your-repo-url>

# 2. Go into the project folder
cd <project-folder>

# 3. Install dependencies
npm install

# 4. Start the dev server
npm run dev
```

Then open the URL shown in the terminal (Vite's default is `http://localhost:5173`).
